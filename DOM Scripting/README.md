Project plan

Project idea
I created a simple to-do list application. It helps users organise their daily tasks. Users can add tasks, complete them, and delete them.

Features
1. Add a new task.
2. Show an error if the task is empty or too short.
3. Mark a task as completed.
4. Delete a task.
5. Save tasks in the browser using localStorage.
6. Show the number of unfinished tasks.

Wireframe
The page has a title at the top, followed by a text input and an Add Task button. Below them, the application shows the number of unfinished tasks and a list of tasks. Each task has a checkbox and a Delete button.

How to use
1. Open the application in a browser.
2. Enter a task in the input field.
3. Click Add Task.
4. Use the checkbox to mark a task as completed.
5. Click Delete to remove a task.

Running locally
Download or clone the repository. Open the project folder and open index.html in a web browser.
